# Zenonia Card Hunters

**Play it here: https://justforzenonia.github.io/ZenoniaCardHunter/**

A cozy pixel card-hunting RPG you can play free in your browser or on Android, alone or with up to three friends.

This repository holds the game's website (published with GitHub Pages) and its small game server (`tools/serve.py`, run on
Render) for online co-op, the market and hero codes.

An unofficial, free fan game made for fun. Not affiliated with or endorsed by Gamevil or Com2uS. Zenonia and its original art
and music belong to their owners.
